# my_neovim_config
It's a my neo vim config, I started with a kickstarter and I change it.

I used the neovim kickstarter for start this project and I am improving it as I go to use it.

This is the beginning of my studies and use of Neovim

Installing:
- Enter on installFiles folder;
- Execute sudo sh install.sh;
- After installing neovim execute nerd-font-install.sh (choose a mono fonts - I use ubuntumono)
- open neovim with nvim and check :Lazy and :Mason.
